Each lab is a self-contained Node.js project in its own folder.

| Folder              | Contents                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `lab1/`             | Lab 01 – development environment setup: minimal page, `greet()` test, ESLint, Prettier, serve |
| `practice-project/` | Practice page with button click events                                                        |

## Running a lab

```bash
cd lab1
npm install
npm start          # serve the public/ folder
node --test        # run the tests
npm run lint       # check JavaScript with ESLint
npm run format     # check formatting with Prettier
```
